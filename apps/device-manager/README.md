# Device Manager

**Технологии:** Node.js, Express.js
**Порт:** 8082
**Назначение:** Микросервис для управления IoT устройствами в системе умного дома

## Основные возможности

### CRUD операции с устройствами

- [`POST /api/v1/devices`](routes/devices.js:58) - Создание нового устройства
- [`GET /api/v1/devices`](routes/devices.js:8) - Получение списка всех устройств
- [`GET /api/v1/devices/:id`](routes/devices.js:24) - Получение устройства по ID
- [`PUT /api/v1/devices/:id`](routes/devices.js:75) - Обновление устройства
- [`DELETE /api/v1/devices/:id`](routes/devices.js:107) - Удаление устройства

### Интеграция с монолитом

- Взаимодействие с существующим монолитным приложением через REST API
- Синхронизация данных датчиков температуры с монолитом

### Валидация данных

- Проверка корректности данных устройств
- Валидация обновлений конфигурации

## Архитектура

Сервис реализует паттерн "Strangler Fig" для постепенного вывода функциональности из монолита. Device Manager служит абстракцией над монолитным API для управления устройствами, обеспечивая единый интерфейс для работы с IoT устройствами.
