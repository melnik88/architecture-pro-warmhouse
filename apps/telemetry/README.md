# Telemetry

**Технологии:** Node.js, Express.js
**Порт:** 8083
**Назначение:** Автоматический сбор и обработка телеметрических данных с IoT устройств

## Архитектура

Telemetry обеспечивает автономный сбор данных без участия пользователя. Сервис взаимодействует с другими компонентами системы через REST API

## Принцип работы

1. При запуске сервис автоматически начинает сбор телеметрии
2. Каждые 10 секунд выполняется цикл сбора данных:
   - Получение списка устройств от Device Manager
   - Для каждого температурного датчика:
     - Запрос актуальной температуры от Temperature API
     - Обновление данных устройства в Device Manager

## Зависимости

Для корректной работы требуются запущенные сервисы:
- Device Manager Service (порт 8082)
- Temperature API (порт 8081)
